# 作興趣 AI｜IG 輪播設計中心 V1.0 網站

單一網站完成：近 7 天露營資訊研究 → 點選題材與參考帳號 → 自動產生/編輯 5–10 張輪播腳本 → 上傳照片或 AI 生成背景 → 1080×1350 PNG **逐張點選下載**。**不含 ZIP、不顯示張數順序、不自動發文**。

## Windows 啟動

安裝 Python 3.10+ 後，雙擊 `start_windows.bat`；或在資料夾執行 `python server.py`，瀏覽器開 `http://127.0.0.1:8765`。無需 Node.js。網站只監聽 127.0.0.1，不會公開到網際網路。

## AI 串接（選用；API 可能收費）

在**啟動網站前**，用 Windows CMD 輸入 `set OPENAI_API_KEY=你的金鑰`，再於同一個 CMD 執行 `python server.py`。金鑰只保留在本機服務環境變數，不會放入網頁或瀏覽器儲存；不要公開金鑰。API 使用 OpenAI Responses（腳本）及 Image Generation（背景圖），文字排版由瀏覽器 Canvas 製作避免生圖文字錯誤。模型預設 `gpt-4.1-mini` 和 `gpt-image-1`；依你的模型權限與帳單可能需要修改 `OPENAI_TEXT_MODEL`、`OPENAI_IMAGE_MODEL` 環境變數。

沒有設定金鑰：可以研究公開新聞、匯入真實來源與帳號、建立**模板腳本**、逐張手動編輯與下載 PNG；不會假裝模板為 AI 生成。

## 研究功能與資料限制

「更新近 7 天資料」向 Google News RSS 取回台灣露營、景點、南投戶外新聞線索（網路連線必要）。來源是**新聞搜尋線索，不是 Instagram 熱門榜**；點擊原始連結查證。若平台阻擋或無網路，畫面顯示錯誤，可用「匯入資料」貼入自有可驗證的 JSON。IG Top10 帳號僅列**使用者匯入且附公開連結**之參考帳號；沒有完整觀測量時不評等、不做排名、不虛構按讚／觀看數。列表最多展示 10 個。來源時間、貼文和指標依提供者提供的內容呈現；不暗示任何外部觀察已驗證。若要自動抓 IG 授權 Insights，需要另外完成 Meta 官方授權與核准權限。

### 匯入格式示例（將範例替換為真實可驗證資料）
```
{
  "topics": [{"title":"議題標題", "category":"露營知識", "published":"2026-11-16", "source":"來源名稱", "url":"https://...", "likes":null,"comments":null,"views":null}],
  "accounts": [{"handle":"@example", "url":"https://www.instagram.com/example/", "category":"露營景點", "source_url":"https://...", "observed_at":"2026-11-16", "likes":null,"comments":null,"views":null}]
}
```
可貼到研究分頁文字框並按匯入。匯入僅保留在當前瀏覽器工作階段；網頁重新整理會清空。資料不是排名。

## 圖片

1. 選擇主題，調整故事素材與張數。
2. 產生模板腳本，或設定 AI Key 後產生真正 AI 腳本。
3. 每張圖片可選本機上傳照片（瀏覽器本地處理）、套用單張／批次圖片，或 AI 生成單張背景圖。
4. 選擇六種風格。每張 Canvas 顯示實際 1080×1350 版面。**圖片上沒有頁碼／順序**，右下角固定 `@interest558855`，50% 半透明暗框與醒目繁體中文字；按每張圖片下的「下載這張 PNG」獨立下載。
5. 客服 LINE 固定 `@wifi558855`、訂位連結 `https://forinterest.hexa.tw/`；複製社群文案另行自行貼到 IG。

## 安全和事實檢查

* 文件、傳聞、照片中的真實人物或虛構事件需出版前人工確認；不得把沒有證據的地方人物故事當成事實。
* 瀏覽器圖片不會傳到伺服器（僅 AI 背景生成的提示文字會送至你設定的 OpenAI API）。
* 網站不會替你發布到 Instagram。
* 當來源無法取得公開互動量時顯示「未取得」，絕不推斷或捏造排名。

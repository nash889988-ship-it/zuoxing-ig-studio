# 作興趣 AI｜IG 輪播設計中心 V2.0

正式網站：https://zuoxing-ig-studio.onrender.com

**免登入、單一網站工作台**：露營知識／旅遊訊息與書籍榜單研究 → 點選主題 → 編輯主題背景、重要素材、閱讀心得與一至八組來源 → AI 精準腳本 → 5–10 張圖片設計 → 單張 PNG 下載。不自動發文，不建立圖片 ZIP。

## V2.0

- **主題對齊**：內容類型可選「知識整理型／閱讀心得型／旅遊攻略型／故事敘事型」；閱讀主題不會強制轉為露營文案。
- **資料依據**：主題故事內容、必須涵蓋的素材、閱讀心得與實際來源文字分開提供。純書名、新聞標題或網址不代表已閱讀來源；材料不足會回覆 `needs_sources` 而非虛構情節。第一人稱心得只在使用者已提供心得時出現。
- **120 字**：每張標題加內文最多120個 Unicode 字元（含標點）。後端驗證張數、字數、Hashtag，失敗會重試一次；前端逐張計數、超字時禁止下載。
- **版面**：六種視覺色系、三種輪替的專業編輯排版；白色標題約54–58 px、內文約29–30 px，依內容動態縮放；輸出尺寸1080×1350。移除左上角 LOGO、不顯示順序；右下保留 @interest558855。
- **來源註記**：腳本可攜帶 `source_ids` 及 `verification_notes`；仍需人工核實書籍、人物與旅遊事實。
- **AI 生圖**：圖像提示與所選主題一致，不會強制產生露營圖像，避免仿製真實書籍封面或人物。
- **下載**：點選圖片或個別按鈕下載 PNG，沒有 ZIP、沒有自動發布。

## 啟用 AI

進入「故事腳本」表單，輸入自己的 OpenAI API 金鑰（僅本頁記憶體、未存 localStorage），由 Render 後端轉送 OpenAI。API 帳務與 ChatGPT 訂閱分開，可能收費。切勿在聊天、GitHub 或不可信網站公布金鑰。沒有金鑰仍可使用研究、非書籍模板、照片排版與下載。

## 研究資料限制

熱門新聞以 Google News RSS 線索呈現，並非 IG 熱度排行榜。IG 參考帳號需透過使用者提供可追溯資料；不足10位不補假排名。書籍榜單為書店分類榜的固定快照，非全台暢銷總排名，也不是自動讀取書籍全文。閱讀心得與摘要須使用者提供可靠內容。

## 本地開發

Windows 需 Python 3.10+，執行 `python server.py`，開啟 `http://127.0.0.1:8765`；Render 使用 `python server.py`，監聽 Render 提供的 PORT。靜態檔案：`index.html`、`app.js`、`style.css`；API 實作：`server.py`。依賴 Python 標準函式庫。

## 安全與限制

網站免登入，所有訪客均可存取其研究與設計介面。付費 AI 呼叫僅使用當次訪客自行提供的金鑰，後端不會默默使用網站所有者的共用金鑰。金鑰仍會經網站後端；請留意第三方主機與自身 API 費用。網站不會自行抓取整本書或驗證所有來源；生成文案不是已完成事實查核。
